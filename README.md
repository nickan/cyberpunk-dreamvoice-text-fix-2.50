# Cyberpunk 2077: DreamVoice Phantom Liberty Text Fix & Dogtown Sync (Patch 2.50+)

Микро-патч, исправляющий сломанный и отсутствующий текст в Cyberpunk 2077 (патч 2.50 и новее) при использовании неофициальной русской озвучки дополнения Phantom Liberty от **DreamVoice** (`Rus_Dub_by_DreamVoice_v5.3.1.archive`), а также приводящий субтитры и текст заданий в полное соответствие с озвучкой («Пёсий город» ➔ «Догтаун»).

---

## 🔍 В чём была проблема?
1. **Сломанный текст патча 2.50:**  
   В архиве мода русской озвучки `Rus_Dub_by_DreamVoice_v5.3.1.archive`, помимо аудиофайлов реплик (.wem), автор случайно запаковал устаревшие текстовые файлы локализации интерфейса (`localizationPersistenceOnScreenEntries`) и диалогов старой версии.  
   В патче 2.50 разработчики игры добавили и изменили сотни строк меню, настроек графики, новых перков, предметов и заданий. Из-за высокого приоритета папки `archive/pc/mod` игра читала старые файлы из мода, где этих строк не было — в результате чего текст в меню и диалогах ломался, появлялись пустые места или технические заглушки (`UI-Script-Localization-String-NotFound`).

2. **Рассинхрон терминологии («Пёсий город» vs «Догтаун»):**  
   В озвучке DreamVoice персонажи называют район **Догтаун**, тогда как в официальных русских текстах и субтитрах CDPR он переведён как «Пёсий город». Это создавало диссонанс между тем, что игрок слышит и что читает на экране.

---

## 🛠️ Что делает этот фикс?
Патч представляет собой компактный .archive контейнер (`###_DreamVoice_Fix_Text_2.50.archive`, ~5.9 МБ), содержащий 146 актуальных файлов локализации для патча 2.50:

- **100% Сохранение русской озвучки:** Патч загружается по алфавиту раньше DreamVoice (`###_...`), возвращая актуальные тексты 2.50, а вся озвучка (27 530 реплик, анимации мимики lipsync и звуковые карты) беспрепятственно загружается следом.
- **Восстановление интерфейса 2.50:** Исправлены все пункты меню, графические настройки, описания предметов, способностей и квестов.
- **Синхронизация с озвучкой (Догтаун):** Во всех меню, журнале заданий, чипах, сообщениях и субтитрах диалогов все формы и падежи «Пёсьего города» аккуратно заменены на кириллический «Догтаун»:
  - *Пёсий город* ➔ **Догтаун**
  - *Пёсьего города* ➔ **Догтауна**
  - *Пёсьему городу* ➔ **Догтауну**
  - *в Пёсьем городе* ➔ **в Догтауне**
  - *Пёсьим городом* ➔ **Догтауном**
  - *пёсьегородский* ➔ **догтаунский**

## 📦 Установка

### Вариант 1 (Вручную):
1. Скачайте архив `DreamVoice_PhantomLiberty_TextFix_2.50.zip` из папки `dist/` или вкладки Releases.
2. Распакуйте архив в корневую папку с установленной игрой `Cyberpunk 2077` (соглашаясь на слияние папок).
3. Убедитесь, что файл появился по пути:
   ```text
   Cyberpunk 2077\archive\pc\mod\###_DreamVoice_Fix_Text_2.50.archive
   ```

### Удаление:
Просто удалите файл `###_DreamVoice_Fix_Text_2.50.archive` из папки `Cyberpunk 2077\archive\pc\mod\`.

---

## 💻 Сборка из исходников
Если вы хотите собрать микро-патч самостоятельно:
```bash
python scripts/pack_mod_archive.py
```

Скрипты в репозитории:
1. `scripts/extract_targets.py` — извлекает конфликтные CR2W из ванильных архивов игры 2.50.
2. `scripts/apply_json_patches.py` — выполняет сериализацию через WolvenKit CLI и применяет грамматически корректную замену «Пёсий город» ➔ «Догтаун».
3. `scripts/pack_mod_archive.py` — сжимает данные с помощью Oodle Kraken (`oo2ext_7_win64.dll`), вычисляет REDengine 4 64-bit CRC и собирает архив с выравниванием по 4096 байт для DirectStorage.
