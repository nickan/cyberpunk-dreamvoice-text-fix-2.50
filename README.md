# Cyberpunk 2077: DreamVoice Phantom Liberty Text Fix (Patch 2.50+)

Микро-патч, исправляющий сломанный и отсутствующий текст в Cyberpunk 2077 (патч 2.50 и новее) при использовании неофициальной русской озвучки дополнения Phantom Liberty от **DreamVoice** (`Rus_Dub_by_DreamVoice_v5.3.1.archive`).

---

## 🔍 В чём проблема?
В архиве мода русской озвучки `Rus_Dub_by_DreamVoice_v5.3.1.archive`, помимо аудиофайлов реплик (.wem), автор запаковал устаревшие файлы локализации интерфейса (`localizationPersistenceOnScreenEntries`) и субтитров.

В патче 2.50 разработчики игры добавили и обновили сотни строк меню, настроек графики (DLSS, FSR, Frame Generation), новых перков, предметов и заданий. Поскольку папка `archive/pc/mod` имеет наивысший приоритет над ванильными файлами игры, движок Cyberpunk 2077 читал старые текстовые файлы из мода, где этих строк не было — в результате чего текст в игре пропадал, отображались пустые поля или технические заглушки (`UI-Script-Localization-String-NotFound`).

---

## 🛠️ Как работает фикс?
Патч представляет собой компактный .archive контейнер (`###_DreamVoice_Fix_Text_2.50.archive`, ~5 МБ), содержащий официальные 144 файла локализации текста для версии 2.50.

- За счёт префикса `###_` патч загружается по алфавиту **раньше** мода DreamVoice.
- Игра берёт актуальный текст версии 2.50.
- Следом загружается архив DreamVoice: игра пропускает устаревший текст, но **загружает 100% озвучки** (все 27 530 реплик, анимации мимики lipsync и звуковые карты).
- Русская озвучка полностью сохраняется, а весь текст в игре работает без ошибок.

## 📦 Установка

### Вариант 1 (Вручную):
1. Скачайте архив `DreamVoice_PhantomLiberty_TextFix_2.50.zip` из папки `dist/` или вкладки Releases.
2. Распакуйте архив в корневую папку с установленной игрой `Cyberpunk 2077` (соглашаясь на слияние папок).
3. Убедитесь, что файл появился по пути:
   ```text
   Cyberpunk 2077\archive\pc\mod\###_DreamVoice_Fix_Text_2.50.archive
   ```

### Удаление:
Просто удалите файл `###_DreamVoice_Fix_Text_2.50.archive` из папки `Cyberpunk 2077\archive\pc\mod\`.

## 💻 Сборка из исходников
Если вы хотите собрать микро-патч самостоятельно:
```bash
python scripts/build_patch.py --game-dir "ПУТЬ_К_ПАПКЕ_ИГРЫ" --out "###_DreamVoice_Fix_Text_2.50.archive"
```

Скрипт автоматически:
1. Извлекает таблицу CRC-64 REDengine 4 из `Cyberpunk2077.exe`.
2. Находит конфликтующие текстовые файлы.
3. Собирает валидный `.archive` (RDAR v12) с правильными контрольными суммами.
